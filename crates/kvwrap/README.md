# kvwrap

Flexible key-value store wrapper with optional distributed capabilities.

This is the main entry point for the kvwrap ecosystem. It re-exports [`kvwrap-core`](https://crates.io/crates/kvwrap-core) and optionally enables [`kvwrap-distributed`](https://crates.io/crates/kvwrap-distributed) and [`kvwrap-client`](https://crates.io/crates/kvwrap-client) via feature flags.

For usage examples, feature flags, and full documentation see the [project README](https://github.com/ryebreadgit/kvwrap).
