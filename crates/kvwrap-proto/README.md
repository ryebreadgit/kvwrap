# kvwrap-proto

Protobuf/gRPC service definitions for kvwrap.

Contains the generated gRPC types used by [`kvwrap-distributed`](https://crates.io/crates/kvwrap-distributed) and [`kvwrap-client`](https://crates.io/crates/kvwrap-client). This is an internal crate and generally should not be depended on directly.

For full documentation see the [project README](https://github.com/ryebreadgit/kvwrap).
