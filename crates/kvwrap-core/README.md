# kvwrap-core

Core traits and backend implementations for kvwrap.

Defines the `KvStore` trait and provides storage backends (Fjall, Sled) behind feature flags. Most users should depend on the [`kvwrap`](https://crates.io/crates/kvwrap) crate instead of using this directly.

For full documentation see the [project README](https://github.com/ryebreadgit/kvwrap).
